# mimimo-pet-mochi

Mochi, a soft pink companion by Flowscape for Mimimo. Original lightweight SVG frames, no remote requests.

```ts
import { createPet } from 'mimimo';
import { mochi } from 'mimimo-pet-mochi';

const pet = createPet({ character: mochi });
pet.play('happy');
```

Install this pet independently. It does not depend on other pet packages. Requires Mimimo 0.1.x. This workspace is a development preview and is not published.
