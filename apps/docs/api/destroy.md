# Clean up an instance

Call destroy when the owner unmounts. It removes the character and its panels, stops rendering, releases gestures and aborts owned asynchronous work. It is safe to call more than once.

<PetDemo topic="destroy" />

## Signature

```ts
pet.destroy(): void
```

| Parameter or method    | Behavior                                               |
| ---------------------- | ------------------------------------------------------ |
| `destroy()`            | Disposes the live instance; repeat calls are harmless. |
| `show() after destroy` | Does not recreate the instance.                        |
| `createPet()`          | Creates a fresh independent instance.                  |

## How it works

A destroyed instance cannot be revived with show. Create a new pet to start again. You still own external timers, listeners, framework roots and other application work. The examples abort their own controller before destroying the pet, including React effect cleanup and Vue unmount.

## Use it in your project

Choose your stack. Each example includes setup and cleanup. For Vanilla, pass a mounted container at least 360px tall and keep the returned cleanup. Method names are identical across frameworks.

::: code-group

```ts [Vanilla]
import { createPet } from 'mimimo';
import { mochi } from 'mimimo-pet-mochi';

// Call after your container mounts.
export function mountCompanion(container: HTMLElement) {
  const lifetime = new AbortController();
  const pet = createPet({
    character: mochi,
    container,
    anchor: 'center',
  });
  pet.say('I will clean up when this component unmounts.');
  return () => {
    lifetime.abort();
    pet.destroy();
  };
}
// Keep the returned cleanup and call it when the view is removed.
```

```tsx [React]
'use client';
import { useEffect, useRef } from 'react';
import { createPet } from 'mimimo';
import { mochi } from 'mimimo-pet-mochi';

export default function Companion() {
  const host = useRef<HTMLDivElement>(null);
  useEffect(() => {
    const container = host.current;
    if (!container) return;
    const lifetime = new AbortController();
    const pet = createPet({
      character: mochi,
      container,
      anchor: 'center',
    });
    pet.say('I will clean up when this component unmounts.');
    return () => {
      lifetime.abort();
      pet.destroy();
    };
  }, []);
  return <div ref={host} style={{ height: 360, position: 'relative' }} />;
}
```

```vue [Vue]
<script setup lang="ts">
import { ref, onMounted, onBeforeUnmount } from 'vue';
import { createPet } from 'mimimo';
import { mochi } from 'mimimo-pet-mochi';
const host = ref<HTMLElement | null>(null);
let cleanup: (() => void) | undefined;
onMounted(() => {
  const container = host.value;
  if (!container) return;
  const lifetime = new AbortController();
  const pet = createPet({
    character: mochi,
    container,
    anchor: 'center',
  });
  pet.say('I will clean up when this component unmounts.');
  cleanup = () => {
    lifetime.abort();
    pet.destroy();
  };
});
onBeforeUnmount(() => cleanup?.());
</script>

<template>
  <div ref="host" style="height: 360px; position: relative" />
</template>
```
